# Serialización y deserialización de árbol binario

Formato preorder de enteros separados por coma, usando # para NULL. El buffer debe tener capacidad suficiente; false indica error o falta de espacio.

```c
bool serializar_27(const nodo_arbol_bin_27_t *raiz, char *buffer, size_t capacidad);
```

El contrato reemplaza el antiguo flujo `val`, que no describía ni implementaba la operación del ejercicio.
