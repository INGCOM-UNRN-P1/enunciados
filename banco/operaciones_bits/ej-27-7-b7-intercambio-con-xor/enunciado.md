Implementá `void swap(int *a, int *b)` para intercambiar dos enteros usando
el operador XOR sin una variable temporal. Ambos punteros apuntan a enteros
válidos. Si apuntan a la misma variable, el valor debe conservarse.

:::{hint} Ayuda
Las tres operaciones XOR revierten el intercambio; tratá por separado el caso
en que ambos punteros señalan la misma variable.
:::
