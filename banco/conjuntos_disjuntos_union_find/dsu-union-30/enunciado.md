# TAD Completo de Partición y Conectividad Dinámica DSU

## 1. Consigna
Implementar y gestionar la estructura de datos **Disjoint Set Union (DSU / Union-Find)** para resolver la operación: **TAD Completo de Partición y Conectividad Dinámica DSU**.
La estructura debe mantener una colección de conjuntos disjuntos identificados por representantes canónicos, optimizando las consultas y fusiones mediante compresión de caminos y unión por rango/tamaño para garantizar una complejidad temporal casi lineal $O(\alpha(N))$.

## 2. Firmas y Prototipos Requeridos
- `int ejecutar_dsu_union_30(int val)`: Procesa el flujo principal de TAD Completo de Partición y Conectividad Dinámica DSU
