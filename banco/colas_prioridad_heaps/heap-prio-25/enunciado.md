# Validación de heap sobre arreglo

Implementá funciones que validen si un arreglo de enteros satisface propiedad de min-heap o max-heap. Para longitud cero se considera válido; con longitud positiva se requiere puntero no nulo. Cada validación debe ejecutarse en O(n) y aceptar duplicados.

La API completa y sus firmas están en `heap-prio-25.h`. Los tamaños son explícitos, los errores se reportan con `bool` y los valores de salida sólo se modifican al completar la operación, salvo que la documentación indique lo contrario.
