# Verificación de Camino Hamiltoniano por Fuerza Bruta

La matriz booleana de adyacencia representa un grafo dirigido. La búsqueda por backtracking decide si existe un camino que visita cada vértice exactamente una vez. Devuelve `1` si existe, `0` si no y `-1` para `n` inválido, puntero nulo o más de 20 vértices. El caso de un vértice tiene camino hamiltoniano.

Consultá `grafo-red-24.h` para la firma completa. Los tests de `ejercicio.yaml` verifican los resultados, las condiciones de error y los casos límite. Compilación requerida: C11 con `-Wall -Wextra -Werror`.
