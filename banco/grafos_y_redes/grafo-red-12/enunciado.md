# Componentes Fuertemente Conexas por Algoritmo de Kosaraju

Calculá las componentes fuertemente conexas de un grafo dirigido y escribí en `etiquetas[v]` el identificador de la componente de cada vértice. Las etiquetas son consecutivas desde cero; su orden es arbitrario.

Índices de vértices desde 0; se admiten hasta 20 vértices.

```c
size_t componentes_kosaraju(size_t n, const int matriz[20][20], int etiquetas[20]);
```
