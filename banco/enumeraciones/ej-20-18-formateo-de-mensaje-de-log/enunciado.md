# Formateo de mensaje de log

Implementar una función que formatee un mensaje de log incluyendo el nivel como
prefijo.



``` c
void log_mensaje(enum nivel_log nivel, const char *mensaje);
```

Ejemplo de salida: `[ERROR] Archivo no encontrado`

## Contrato

Implementá la API declarada en `ej-20-18-formateo-de-mensaje-de-log.h`. La función debe respetar los rangos documentados y manejar entradas inválidas sin acceso fuera de rango.

## Compilación

Usar C11 con `-Wall -Wextra -Werror`.
