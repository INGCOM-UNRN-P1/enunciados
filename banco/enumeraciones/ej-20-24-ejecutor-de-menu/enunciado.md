# Ejecutor de menú

Implementar una función que ejecute la acción correspondiente a cada opción del
menú.



``` c
void ejecutar_opcion(enum opcion_menu opcion);
```

## Contrato

Implementá la API declarada en `ej-20-24-ejecutor-de-menu.h`. La función debe respetar los rangos documentados y manejar entradas inválidas sin acceso fuera de rango.

## Compilación

Usar C11 con `-Wall -Wextra -Werror`.
