# Validación de cabecera

Implementar una función que valide que los valores de una cabecera están dentro
de los rangos permitidos.



``` c
bool cabecera_valida(cabecera_mensaje_t cabecera);
```

## Contrato

Implementá la API declarada en `ej-20-20-validacion-de-cabecera.h`. La función debe respetar los rangos documentados y manejar entradas inválidas sin acceso fuera de rango.

## Compilación

Usar C11 con `-Wall -Wextra -Werror`.
