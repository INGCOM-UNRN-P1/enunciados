# Detectar conflictos

Implementar una función que detecte combinaciones incompatibles de opciones.



``` c
bool opciones_compatibles(unsigned int opciones);
```

Por ejemplo, `OPT_OPTIMIZAR` y `OPT_DEBUG` podrían considerarse incompatibles en
ciertos contextos.

## Contrato

Implementá la API declarada en `ej-20-22-detectar-conflictos.h`. La función debe respetar los rangos documentados y manejar entradas inválidas sin acceso fuera de rango.

## Compilación

Usar C11 con `-Wall -Wextra -Werror`.
