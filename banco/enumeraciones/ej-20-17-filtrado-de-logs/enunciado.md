# Filtrado de logs

Implementar una función que determine si un mensaje debe ser registrado según el
nivel mínimo configurado.



``` c
bool debe_registrar(enum nivel_log nivel_mensaje, enum nivel_log nivel_minimo);
```

## Contrato

Implementá la API declarada en `ej-20-17-filtrado-de-logs.h`. La función debe respetar los rangos documentados y manejar entradas inválidas sin acceso fuera de rango.

## Compilación

Usar C11 con `-Wall -Wextra -Werror`.
