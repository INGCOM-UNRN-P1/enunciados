# Consultas espaciales 2D por rango

Implementá un índice KD-tree estático balanceado para puntos 2D y consulta de caja axis-aligned inclusiva. API de construcción desde arreglo, consulta que escribe índices originales hasta capacidad dada y reporta total encontrado, destrucción. Validá finitud, capacidad y overflow; resultados en orden ascendente de índice.

Las firmas y tipos están definidos en `geom-comp-30.h`. La API documenta los casos vacíos, errores y límites de capacidad.
