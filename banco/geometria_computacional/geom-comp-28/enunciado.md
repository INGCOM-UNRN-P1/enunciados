# Intersección de rectas paramétricas

Representá puntos y vectores 2D con double. Implementá intersección de p+t*r y q+u*s. Clasificá como única, paralela distinta o coincidente usando tolerancia epsilon y entrega el punto sólo cuando hay solución única. Rechazá punteros nulos, epsilon negativo/no finito y entradas no finitas.

Las firmas y tipos están definidos en `geom-comp-28.h`. La API documenta los casos vacíos, errores y límites de capacidad.
